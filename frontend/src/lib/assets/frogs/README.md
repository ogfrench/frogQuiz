# Frog avatars

The frog each player is given in a live game. The game picks one by seat number
(`src/lib/play/avatars.svelte.ts`), in file-name order, so adding or removing a file here
is all it takes to change the set.

- **Source**: generated by Gonçalo with Microsoft Copilot on 2026-10-08, as 21 SVGs that
  each wrapped a PNG. Numbers 10 and 12 were left out, which is why the names skip them.
- **Processing**: the PNG taken out of each SVG, trimmed to the drawing, centred on a
  square with an 8% margin, and saved as lossless WebP (about 30 KB each, against 60-85 KB
  for the SVG wrappers).
- **Transparency**: the backgrounds are clear, but the frogs themselves are drawn at about
  90% opacity, which is why `FrogAvatar` puts them on an opaque circle.
